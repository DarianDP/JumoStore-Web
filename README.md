JumoStore is a frontend layout for a beverage and liquor e-commerce store. 

## 📖 About the Project

I created JumoStore as a personal project to get started in the world of web design and frontend development. My main goal was to build a complete website layout from scratch to understand how the core building blocks of the web work together before jumping into any complex frameworks.

## ✨ Features

<img width="1916" height="866" alt="image" src="https://github.com/user-attachments/assets/e08c0bfe-16eb-4f23-9504-ac621155b548" />



- **Storefront Layout:** A clean, themed user interface for browsing categories like Beer, Wine, Rum, and Whisky.
- **Interactive Carousel:** A custom-built banner slider to display promotions and featured products.
- **Product Grid:** A "Top Seller" section displaying product images, titles, and localized pricing in Dominican Pesos (RD$).
- **Navigation & Footer:** Includes a sticky navigation header, search input, a visual shopping cart counter, and a footer with integrated Google Maps directions.

## 🛠️ Technologies Used

This project was built completely from scratch using:
- **Vanilla HTML5**
- **Vanilla CSS** (using Flexbox/Grid for layout)
- **Vanilla JavaScript** (for interactive elements like the carousel)
- *No external CSS or UI frameworks were used.*

## 🧠 What I Learned

Since this was my introduction to web development, the biggest challenge for me was getting used to structuring the page using `div` sections. It also took time to understand how to correctly link external CSS stylesheets and JavaScript files to the main HTML document, but figuring it out gave me a solid foundation in how standard web pages operate. 

## 🚀 Future Improvements

While this is currently a static frontend layout, I plan to expand this project in the future by:
- Linking the frontend to a real database to manage products dynamically.
- Integrating a payment processing system to handle actual checkouts and payouts.
